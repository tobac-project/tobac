# AI Policy
"AI" in this document refers to generative AI tools, such as large language models (LLMs; e.g., Claude, ChatGPT, Gemini, etc.) that can generate, edit, and review  code, create and manipulate images, or generate human-like communication.

## Responsibility
You are responsible for any code you submit to *tobac*, regardless of whether it was manually written or generated by AI. You must *understand and be able to explain* the code you submit as well as the existing related code. It is not acceptable to submit a patch that you cannot understand and explain yourself. In explaining your contribution, do not use AI to automatically generate descriptions. Using AI to generate or help generate documentation (e.g., docstrings, documentation pages, examples) is acceptable. 

## Disclosure
You must disclose whether AI has been used to assist in the development of your pull request. If so, you must document which tool(s) have been used. We have the right to reject any pull request that does not include the disclosure.

## Code Quality
Code generated by AI can be of low or high quality. Contributors are expected to submit code that meets *tobac*'s standards. We will reject pull requests without thorough review that we deem being "AI slop". Some examples of this include PRs that:

- Do not explain why they are needed or what their purpose is
- Include unexplained and irrelevant changes outside the scope of the PR
- Contain hallucinated APIs or references, especially hallucinated references to peer-reviewed literature

Do not waste developers' time by submitting code that is fully or mostly generated by AI and doesn't meet our standards. Ensure that any scientific changes are completely understood by you and can be explained by you.

## Copyright
All code in *tobac* is released under the BSD 3-clause copyright license. Contributors to *tobac* license their code under the same license when it is included into *tobac*'s version control repository. That means contributors must have the right to submit the code under the BSD 3-Clause License. Code generated by AI may infringe on copyright, and it is the submitter's responsibility to not infringe. We reserve the right to reject any pull requests, AI generated or not, where the copyright is in question.

## Communication
When interacting with developers (forum, email, discussions, issues, pull requests, etc.) do not use AI to speak for you, except for translation or grammar editing. If the developers want to chat with a chatbot, they can do so themselves. Human-to-human communication is essential for an open source community to thrive.

## AI Agents
The use of an AI agent that writes code and then submits a pull request autonomously is not allowed, but you are allowed to use AI agent driven tools to submit the pull request for you, especially in the case of new developers who do not yet know how to do a pull request. A human developer must be available to answer questions, especially scientific questions, about the code. A human must check any generated code and submit a pull request according to the 'Responsibility' section above.
